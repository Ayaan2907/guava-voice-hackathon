Healthcare scheduling · Calendar slots

Slot Board

Visual calendar board fed by calendar_slot search — dental scheduling with DatetimeFilter.

BENCH Vertical: Healthcare scheduling

What it is

A voice agent schedules appointments via searchable calendar_slot fields while a Next.js board highlights available slots as the caller narrows their preference ("Tuesday afternoon"). Uses onSearchQuery + DatetimeFilter helper — essentially the official scheduling pattern with a visual layer.

Why it matches real Guava

  • calendar_slot Field — ISO-8601 choices, searchable mode per Field docs.
  • onSearchQuery — dynamic slot filtering per Tasks / search fields.
  • DatetimeFilter helper — used in official example scheduling-outbound.ts (Bright Smile Dental).
  • Healthcare scheduling — core Guava vertical on goguava.ai.
  • reachPerson — outbound pattern in scheduling example (skip tonight — inbound WebRTC only).

Architecture

Node Expert — adapt scheduling-outbound to inbound WebRTC:

import { DatetimeFilter } from "@guava-ai/guava-sdk/helpers";
import { mockAppointmentsForFuture } from "@guava-ai/guava-sdk/example-data";

const datetimeFilter = new DatetimeFilter(mockAppointmentsForFuture());

agent.onSearchQuery("appointment_time", async (_call, query) => {
  return datetimeFilter.filter(query, { maxResults: 3 });
});

Next.js — slot board UI; highlight slots returned from search-query events on your bridge (Expert logs search results).

Inbound: use listenWebrtc() instead of callPhone(). Mock appointments from SDK example-data — no external calendar API.
