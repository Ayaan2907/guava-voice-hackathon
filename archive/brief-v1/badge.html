Build Night Brief Idea 07 · BENCH

Event intake · Consent capture

Badge / Consent Desk

Voice agent at the door — collect name, org, and recording consent via Fields. Wing Mic-adjacent, not a wrap.

BENCH Vertical: Healthcare / Government intake

What it is

A WebRTC kiosk at House of AI check-in: Grace asks for your name, organization, and whether you consent to recording for the demo. Fields populate a live badge preview on a tablet. Mirrors healthcare/government consent flows — structurally similar to event intake, but explicitly not wrapping Wing Mic (wingmic.xyz).

Why it matches real Guava

  • Healthcare intake — named vertical on goguava.ai and FAQ.
  • Consent language — Guava's own homepage demo form includes recording consent copy (goguava.ai "Have Guava call you" section) — structurally parallel.
  • multiple_choice Field — yes/no consent capture per Field docs.
  • Task checklist — name (text), org (text), consent (multiple_choice choices=["yes","no"]) per Tasks.
  • WebRTC widget — embed at kiosk (WebRTC Widget).
  • BAA / HIPAA story — consent + audit trail via Conversations API post-call (Conversations API).

Architecture

Node Expert

await call.setTask({
  taskId: "checkin",
  objective: "Collect event check-in details for Guava Build Night.",
  checklist: [
    guava.Field({ key: "full_name", fieldType: "text", description: "Attendee full name" }),
    guava.Field({ key: "organization", fieldType: "text", description: "Company or affiliation" }),
    guava.Field({
      key: "recording_consent",
      fieldType: "multiple_choice",
      choices: ["yes", "no"],
      question: "Do you consent to recording for tonight's demo?",
    }),
  ],
});

Next.js — badge card UI driven by field-complete events; optional print/export. No Wing Mic integration.

"Post-call, Conversations API stores the audit trail. Same primitives as patient intake — applied to tonight's room."

How you win (if you pick this)

  • Meta — demo IS the event check-in (memorable if flawless)
  • Consent story resonates with regulated verticals
  • Simple checklist — low Expert complexity

Why BENCH: Too close to meta-gimmick; doesn't showcase supervisor/"one log" gap. Wing Mic adjacency risks looking like a clone. Glass Box tells a stronger Guava product story.

Risks & fallback

  • Room noise at check-in — bad first impression
  • Consent "no" path — need graceful hangup via hangup()
  • Fallback: pre-recorded check-in via roleplay()

What NOT to do

  • Don't integrate with or wrap Wing Mic
  • Don't build AdvanceIQ / Power BI features
  • Don't use outbound SMS for badge delivery — WebRTC only
  • Don't skip consent no-path — regulated story requires it
