Bilingual FNOL · Language mode

Language Chip

English/Spanish FNOL with a console language indicator — toggle via setLanguageMode, not a second app.

FOLD IN → Glass Box Vertical: Insurance / Healthcare (HITRUST)

What it is

A small UI chip in the Glass Box supervisor console showing active language (EN/ES). The Expert calls setLanguageMode(primary="english", secondary=["spanish"]) at call start. When the caller switches to Spanish, the chip updates — inferred from transcript content since Guava admits there is no per-turn language marker.

Why it matches real Guava

  • set_language_mode() — primary + secondary languages; agent switches when caller speaks or requests (set_language_mode docs).
  • Doc example uses insurance — "Harper Valley Property Insurance" with EN/ES on same page.
  • Transcript caveat — "no per-turn language marker" — your chip must infer from utterance text or manual toggle, don't invent API.
  • HITRUST/PCI languages — EN+ES only for compliant deployments; FR/DE/IT available but not HITRUST/PCI per docs.
  • Voices — grace has ES/FR/DE/IT clones; auto-switches TTS on language detect.
  • Property insurance example: property-insurance.ts.

Architecture

Expert — in onCallStart:

await call.setLanguageMode({
  primary: "english",
  secondary: ["spanish"],
});

Verify TS signature after guava create — docs show both Python and TypeScript tabs.

Console — Language chip component; update on onCallerSpeech events using simple heuristic (Spanish function words) OR supervisor manual toggle that sends message to Expert via your bridge (custom — not a Guava API).

4-hour execution plan (as Glass Box add-on)

  1. 6:15–6:25Add setLanguageMode to Expert onCallStart
  2. 7:30–7:45Chip UI + heuristic from transcript events
  3. 8:00–8:10Rehearse EN→ES switch: "Prefiero hablar en español"

Demo script (~15s insert)

"Harbor Mutual serves bilingual callers. Guava's setLanguageMode handles EN/ES — HITRUST-compliant languages. Watch the chip flip when I switch to Spanish. Docs note there's no per-turn language tag in transcripts — we infer it live in the supervisor console."

How you win

  • Shows regulated-industry awareness — bilingual FNOL is real insurance ops
  • Honest about doc limitations — eng respect for not inventing APIs
  • 15 minutes of work, strong narrative beat

Risks & fallback

  • Language detection heuristic wrong — use manual chip toggle for demo
  • Room noise — pre-script the Spanish phrase
  • Fallback: mention setLanguageMode in script, show chip static at ES

What NOT to do

  • Don't build a separate Spanish-only app
  • Don't claim per-turn language tags — docs say they don't exist
  • Don't demo FR/DE/IT if pitching HITRUST/PCI compliance story
